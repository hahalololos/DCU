# Qwen3.5-27B LLMM1 rows_per_block 调优计划

时间：2026-07-13 17:04 CST

## 目标

以 `0adf049` 为基线，利用现有 LLMM1 已支持的 `rows_per_block=2/4/8/16`，筛选四个
已允许 27B Decode GEMV 形状的最优配置；不开发新 kernel，不立即修改生产 dispatch。

## 实验

- 形状：GDN qkvz、GDN b/a、full-attention qkv+gate、MLP gate-up。
- 同一常驻进程内比较 `F.linear` 和四种 rows，5 次预热、5 轮正反向顺序、每轮至少
  10 次调用。
- 记录 median、P99、相对 row4 加速、与 row4 的 bitwise 一致性及相对 `F.linear` 误差。
- 按 `48/48/16/64` 次每 token 调用数估算组合 Decode 收益。

## 门禁

- 单形状相对 row4 至少提升 5%，且 P99 不稳定回退。
- 优先要求与 row4 bitwise 一致；否则必须满足现有 BF16 Linear 精度标准。
- 组合预测 Decode 收益至少 1.5% 才允许改为按形状 rows 映射并进入短、中档端到端测试。
- 未通过则不修改 `vllm_cscc`，只保留 profile 工具和实验结论。
