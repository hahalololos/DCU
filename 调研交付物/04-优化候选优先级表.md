# 优化候选优先级表

优先级按照评分权重和风险排序：优先服务 `8k-16k` 档位，其次 `16k-32k`，最后 `4k-8k`。任何优化都必须满足 SLA 和精度约束；没有实测数据前，收益均为预估。

| --- | --- | --- | --- | --- | --- | --- | --- |

## 2. 第一轮实验建议

### 实验 A：Baseline + profiler 热点画像

目标：回答 baseline 慢在哪里。

采集：

| 项 | 内容 |
| --- | --- |
| 性能 | 三档 Throughput、TTFT P50/P90/P99、TPOT P50/P90/P99 |
| 显存 | 启动后权重占用、峰值、KV cache size、num blocks |
| kernel | Attention、Linear/GEMM、RMSNorm、sampling、memcpy 占比 |
| 稳定性 | 完成率、P99/P50 比值、是否有异常重试或 OOM |

通过标准：

1. 能明确每档 TTFT/TPOT 的主要耗时来源。
2. 能判断 8k-16k 档位是 prefill、decode 还是显存瓶颈。
3. 能识别 Qwen3.5 linear attention 是否走慢路径。

### 实验 B：KV Cache block 与显存效率画像

目标：验证长上下文下是否存在可优化的 block waste、碎片或 allocator 开销。

采集：

| 项 | 内容 |
| --- | --- |
| block size | 默认值与实际 resolved block size |
| num_gpu_blocks | 启动日志和运行期变化 |
| 单请求 block 使用量 | 三档请求实际分配块数 |
| last block waste | `ceil(seq_len / block_size) * block_size - seq_len` |
| 显存峰值 | 三档请求运行期峰值 |
| allocator 行为 | 是否有运行期频繁分配/释放 |

通过标准：

1. 能量化单请求不同长度下的 block waste。
2. 能判断是否值得改内部块管理策略。
3. 不触碰外部锁定参数，避免合规风险。

### 实验 C：Decode fast path 可行性

目标：并发固定为 1 时，确认是否能减少通用调度和小算子开销。

采集：

| 项 | 内容 |
| --- | --- |
| 每 token Python 调用栈 | decode loop 中 CPU 侧耗时 |
| kernel launch 数 | 每 token step 的 kernel 数量 |
| sampling 耗时 | temperature=0 下 logits/sampling 处理时间 |
| 同步点 | CPU-GPU sync、memcpy、事件等待 |

通过标准：

1. 找到明确的固定开销热点。
2. 方案不改变 scheduler 语义、不改锁定参数。
3. 小规模实现后 TPOT P99 不上升，TTFT P99 不上升。

## 3. 风险控制

| 风险 | 控制方式 |
| --- | --- |
| SLA 熔断 | 每个实验都同时记录 TTFT P99 和 TPOT P99，任一恶化超过 10% 先暂停 |
| 精度下降 | 涉及低精度、kernel 替换、sampling 路径时必须跑 OpenCompass |
| 合规不确定 | 先写入 `01-合规边界清单.md` 的高风险项，等官方确认后再做 |
| 平台不可复现 | 所有依赖和 custom kernel 编译脚本随源码提交，禁止评测期联网 |
| 过拟合数据集 | 只按长度档位和通用算子路径优化，不写 prompt/content if-else |

## 4. 推荐阶段安排

| 阶段 | 目标 | 产出 |
| --- | --- | --- |
| D1 | 跑通 baseline 和 profiling | 完整三档性能表、kernel 时间线 |
| D2-D3 | KV Cache 与 attention 路径源码阅读 | 可修改点列表、合规判定 |
| D4-D6 | 实现第一个 P0 小实验 | 吞吐/TTFT/TPOT/显存对比 |
| D7 | 精度回归与文档整理 | OpenCompass 结果、优化说明草稿 |

## 5. 决策门槛

一个优化方向进入实现阶段，必须满足：

1. 对 8k-16k 或 16k-32k 有明确指标收益路径。
2. 合规状态为“允许”或“风险但已确认允许”。
3. 有明确回滚方式。
4. 有独立验证命令。
5. 不依赖评测期外部网络。
